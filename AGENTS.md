# Trabajar en este módulo

Sigue el punto de entrada hasta `BlogEntitySchemas`, el servicio de dominio o
el lector público. Reutiliza el handler, la consulta pública y el kit de Core
que cubren el caso. Conserva publicación, permisos, idioma, mercado y privacidad.

Ejecuta PHP y Composer en Docker con datos de prueba. [Mantenimiento](docs/MAINTENANCE.md) · [Convenciones de Core](https://github.com/dbravoan/dbcms-core/blob/main/docs/CONVENTIONS.md)
