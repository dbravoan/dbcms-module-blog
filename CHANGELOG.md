# Changelog

Todos los cambios notables de este proyecto se documentan en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es/1.1.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [Sin publicar]

## [1.2.0] - 2026-11-13

### Añadido

- Fuente pública declarada para composiciones dinámicas y referencias editoriales paginadas con contexto.
- Extracción de contenido anidado para cuerpo y semántica.


## [1.1.0] - 2026-11-12

### Añadido

- Pantalla de moderación de comentarios con aprobación y eliminación.

### Corregido

- Las traducciones públicas del blog y sus categorías no caen a otro idioma.
- Las notificaciones de comentarios enlazan a la bandeja de moderación.

- La dependencia mínima de core pasa a `^1.1` por las APIs compartidas que utiliza este paquete.

## [1.0.0] - 2026-11-05

### Añadido

- Primera versión pública.
- `dbravoan/dbcms-module-blog` aporta artículos de blog, categorías y comentarios. Instala/activa `blog` y configura slugs y comentarios.
